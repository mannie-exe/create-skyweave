# Create Sky 0.1.36

Create Sky Compat 0.19.0 keeps text displays and entity names readable with
independent Iris lighting adaptations. Both default on, alongside the separate
cast-shadow exclusions. Change them under Client → Iris. Later shader color
processing can still affect appearance.

The configuration footer hint now aligns with the button row. Minecraft,
NeoForge, terrain generation and other dependency versions are unchanged.
Existing worlds, seeds and LOD caches need no regeneration.

Previous release: [0.1.35](releases/0.1.35.md).
