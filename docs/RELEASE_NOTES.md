# Create Sky 0.1.25

Add Absolute Kinematics 1.0.1 for driven hinges and passive ball joints. Native
recipes and mass defaults remain. Two Workshop journal entries introduce the
equipment and control differences; the hinge entry supplies two shafts toward
an additional drive setup. The journal contains 72 entries in nine chapters,
with 24 offering fixed rewards. Existing entry mechanics and rewards remain.

Update Create Sky Compat to 0.10.1 for six Linear Bearing Ponder tutorials and
optional Jade brake/link inspection. Add English names for internal carriage
blocks and correct the gyro advancement's old stabilization description.
Shader reload moves from R to F8; existing installations retain other bindings.

Refresh the Atlas's registered content, recipes, journal and compatibility notes.
No world generation, seed, player-progress or LOD identity change is intended.

Previous release: [0.1.24](releases/0.1.24.md).
