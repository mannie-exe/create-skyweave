# Create Sky 0.1.28

Update Create Sky Compat to 0.13.0. Its configuration screen now groups settings
by Client, Server / shared, World generation, and Status & files, with mod sections.
Short summaries keep controls readable; Details contain activation reasons,
dependencies, file locations and defaults.

Journal display preferences apply immediately from either settings entrance.
Startup fixes use Save changes and require a restart; saving does not change
running adaptations. The editor preserves omitted defaults, detects external edits
and retains drafts on failure. Village tuning rejects inverted distance ranges.

Existing configuration keys and defaults remain valid. There are no gameplay,
recipe, quest, generation or LOD-identity changes. Preserve worlds, caches and
personal settings; no regeneration is needed.

Previous release: [0.1.27](0.1.27.md).
