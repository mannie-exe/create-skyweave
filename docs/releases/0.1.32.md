# Create Sky 0.1.32

## Modpack resources

Update Create Sky Compat from 0.14.0 to 0.15.0. Its client adapters restore visible
window faces at mixed Create glass boundaries and between differently oriented
Rechiseled glass pillars, preserving native connected textures. Both repairs are
enabled by default; matching glass interfaces keep their existing culling.

Fix missing Lootr barrel sprites in the block atlas. Trapped Lootr chests now use
the approved directional artwork while retaining their red markers. Restore the
selected azalea shrub geometry and compose both azalea variants with Fresh Flower
Pots. Other selected models and animations retain their existing treatment.

The rejected resource-only window workaround is disabled. The sloped bridge
lantern study remains outside the playable stack pending interaction-bound fixes.

## Atlas and authoring

Local authoring now uses one workspace service for bounded jobs, revision checks,
source saves and generated artifacts. WebSocket updates refresh clean views while
preserving drafts and identifying conflicts. Activity includes job results,
cancellation and recovery controls. CLI generation uses the same operations.

Runtime profiles identify the supported Minecraft/NeoForge environment and its
resource adapters. Static builds expose checked snapshots without local authoring
or a live connection. Resource reviews include the glass comparisons and updated
repair evidence; native exports and generated previews share their input checks.

Minecraft 1.21.1, NeoForge 21.1.264 and all other dependency selections are unchanged.
Terrain generation, seeds and LOD policy are unchanged; existing worlds need no
regeneration.
