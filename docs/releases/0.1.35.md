# Create Sky 0.1.35

Create Sky Compat 0.18.0 combines configuration groups into one scrollable document with section navigation. Drafts, focus and scroll position survive control changes and resource reloads.

Two optional client settings can exclude text displays and entity nametags from Iris shader shadows. Both default off; enable them under Client → Iris. Normal text rendering and entity-body shadows are preserved.

BSL now ships as a complete Colorwheel-patched shader generated by the authoring lab. Plain BSL and the runtime Colorwheel Patcher are no longer included. Complementary/Euphoria remains the default shader.

Minecraft, NeoForge, terrain generation and other dependency versions are unchanged. Existing worlds, seeds and LOD caches remain usable without regeneration.

Previous release: [0.1.34](0.1.34.md).
