# Create: Skyweave 0.3.0

Update Sky Archipelago to 1.4 and Skyweave: Compatibility Patches to 0.23.0.
This generation update requires a fresh expanded-preset world. Preserve existing
worlds and their LOD databases in backups; do not continue their generation with
this release. Installing the pack does not reset worlds automatically.

## Terrain and structures

Use Sky Archipelago's native island exteriors, rivers, lakes and water archetypes
while retaining Skyweave's sparse clusters, variable elevation, island-relative
geology, ores, cave biomes and BASELINE/NOISE/HOLLOW interiors. Cluster spacing
remains 2,400 blocks with up to 750 blocks of jitter in each axis; whole-cluster
clearance accounts for native island bounds. Optional coastal and falling-perimeter
water islands build on native Lagoon/Reef profiles. Global ocean generation stays
disabled.

Place Ancient Cities within eligible island bodies. Normal and NOISE hosts require
90% exterior burial by default, allowing some exposed ruins; HOLLOW hosts need a
supported central floor and roof. Piece-aware bounded clearance opens rooms around
native city pieces while protecting the island shell, foundations, fluids and
river beds. Ordinary villages and Sky Villages may coexist. Reject invalid
structure starts before Surveyor tries to map them.

Native checks covered multiple seeds, representative land and water profiles,
city rooms and foundations, save/reload, actual ore veins, neighboring villages,
other major structures, DH lifecycle and BlueMap bounds. These checks do not
establish complete biome/structure coverage or balanced resource scarcity.
Isolated point-height queries remain substantially slower than the previous
implementation; see [generation verification](../development/worldgen.md).

## Resources and Atlas

Rename the shared resource-only JAR to **Skyweave: Resource Patches** and the
client resource pack to **Skyweave: Visual Patches**. Their generators, metadata,
authoring references and Atlas views use the same identities. The rename retains
the approved resource content. Existing clients must select the renamed visual
pack above its inputs; editable options are preserved during updates.

Refresh Atlas runtime data and generation guidance for the selected dependencies.
Saved-world map and ore evidence keeps its original provenance; it is not a survey
of a newly generated 1.4 world.

Minecraft remains 1.21.1 and NeoForge remains 21.1.265. Server defaults remain view
distance 12 and simulation distance 16. See [included content](../MODLIST.md) for exact
pins and [generation maintenance](../development/worldgen.md) for tuning and limits.
