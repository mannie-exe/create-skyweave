# Create: Skyweave 0.3.1

Fix connected glass-pane appearance with Skyweave: Compatibility Patches 0.23.1
and updated Skyweave: Visual Patches.

- Preserve Fusion's pane-edge culling before adding interior backfaces. Stacked
  panes no longer show the extra horizontal strips visible from above.
- Correct the ambient-occlusion property in 68 Midnighttigger connected-pane
  models, keeping their geometry, connected textures and authored lighting values.
- Update the Atlas resource notes and include the lighting generator in resource
  build fingerprints so previews rebuild when that generator changes.

Native checks covered shaders off/on, exposed and shared edges, mixed colors,
partial connections and resource reload. The owner also reviewed and accepted the
combined changes in the playing client.

Minecraft remains 1.21.1 and NeoForge remains 21.1.265. Generation, world data,
LODs, server distances and progression are unchanged; this patch requires no world
reset. Keep the Visual Patches resource pack above its inputs.
